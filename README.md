# codex-practice

This repository contains practice exercises for working with Git and GitHub.

## Getting Started

1. Clone the repository.
2. Make your changes in a new branch.
3. Commit your updates with meaningful messages.
4. Push the branch and open a pull request for review.

## Repository Goals

- Experiment with version control workflows.
- Practice writing clear commit messages.
- Get comfortable preparing pull requests.

Feel free to add new practice tasks or improve the documentation as you go.
